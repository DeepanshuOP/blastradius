
Requirements:

- Output `data/frame/repos.csv` with columns: `repo` (`owner/name`), `language`, `stars`, `commits`, `contributors`, `default_branch`, `licence`, `last_commit_at`, `frame_version`.
- `frame_version` is a string like `frame-2026-08-05` — it is a **frozen identifier** written into every downstream instance (see `docs/SCHEMAS.md`). Never mutate a frame in place; write a new version.

- Write `data/frame/ATTRITION.json` with `{stage: {name, n_in, n_out, reason}}` as an ordered list.
- No network calls in this module. It is pure CSV → CSV.
