# RQ4 / E3: change-aware repair on BR-Seeded

Generated by `analysis/rq4_repair.py` at git `c987ad509944a5f1e6331c12c5755ee1b05a31fd`.

Produced by `make repair-eval` from cached LLM responses under D-58. It is NOT part of `make tables`, and its repair numbers depend on the recorded model replies (`eval/llm_cache/`). Detection and retrieval need no model.

BR-Seeded: one mutation operator applied to a function covered by the suite (so at least one test fails), plus 2-3 harmless distractor edits in other files; the diff is the 'PR'. A patch is accepted only if the FULL suite (minus tests already failing at the base) passes. Seeded bugs are simpler than real ones; this measures what retrieval and change-awareness add, not absolute repair ability.
