Generated by `analysis/infra_failure_audit.py` at git `ef096551b42590ff545ae1b6a64e59873d5e1201`.

Measurement only: no label is changed or removed from `outcomes.parquet`. The classification is regex-based on the parsed failure message and is a lower bound on environment failures wherever the message is empty.

## Patterns used (decision order)

- 1. leading-assertion (message start) -> code-level: `^\W*(assertionerror|assert\b|expected\b|\d+ expectations? failed|.{0,120}==> expected)`
- 2. cuda-gpu-unavailable -> environment: `no cuda gpus|cuda (error|driver|runtime)|cuda.{0,30}(not available|unavailable)|(no|without) gpu|gpu.{0,30}(not available|unavailable)|torch\.cuda|nvidia-smi`
- 2. out-of-memory -> environment: `out ?of ?memory|outofmemoryerror|\bMemoryError\b|\boom\b|cannot allocate memory`
- 2. connection-error -> environment: `connectionerror|connection (refused|reset|aborted|closed)|connectexception|ssl(error|handshake)|network is unreachable|broken pipe|failed to connect|could not connect|http response code: (429|5\d\d)`
- 2. dns-error -> environment: `unknownhostexception|name or service not known|temporary failure in name resolution|getaddrinfo|nodename nor servname|no such host`
- 2. missing-service -> environment: `service (is )?(not available|unavailable)|serviceunavailable|docker.{0,40}(not running|daemon)|cannot connect to the docker|no such container|testcontainers|can.t get docker image`
- 3. timeout -> timeout: `\bTimeoutError\b|\bTimeout(Exception|Expired)\b|\bConditionTimeout(Exception)?\b|\bSocketTimeout(Exception)?\b|\b(Read|Connect)Timeout\b|(?<![\w-])timeout(?![\w-])|(?<![\w-])timed?[ -]?out(?![\w-])|(?<![\w-])deadline exceeded(?![\w-])`
- 4. assertion -> code-level: `assertionerror|\bassert\b|assertion failed|assertionfailed|expectation failed`
- 4. expected-vs-actual -> code-level: `expected:?\s*<?\[?.{0,200}?\s(but was|but got|actual)|expected.{0,80}\bbut\b.{0,40}\b(was|got|found)\b|did not expect|not equal to|should (be|not)|to be thrown|no exception was thrown`
- 5. no match, or empty message -> unknown

Per-label rule: code-level if any of the label's rows is code-level, else environment if any is, else unknown.
