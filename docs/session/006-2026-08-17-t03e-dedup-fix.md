# T0.3e — stop the dedup branch reading the whole log back off disk

`_fetch_job_log`'s already-complete branch sized a skipped log by gunzipping it
(`sum(len(record.body) for record in store.read_records(...))`). Stage 4 is a
long capture that resumes constantly, so every resume decompressed every
previously-captured log — roughly 2.1 GB of wasted decompression per resume on
the current 10-repo corpus — for a number nobody uses. Specification error, not
an implementation mistake.

Decision implemented as given: the dedup branch returns **None** for the byte
count, not the compressed on-disk size. Compressed and uncompressed bytes are
different quantities; routing either through the same field would make the
middle element mean two different things depending on the branch. The
orchestrator will count dedup skips separately. After this change the middle
element means exactly one thing: bytes actually fetched over the network this
invocation.

Scope: `src/harvest/daemon.py`, `tests/test_daemon.py`. Nothing else.
Per ROADMAP §8.3 T0.3 endpoint 9, §35 T0.3e; DECISIONS.md D-23.

## Step 2 — Implement

Dedup block of `_fetch_job_log`, **after**:

```python
    existing = cursor.get_capture_unit(repo_full, "logs", job_id)
    if existing is not None and existing.status != "in_flight":
        return PR_UNIT_SKIPPED_ALREADY_DONE, None, None
```

The `store.read_records` call is gone. `store` stays in the signature — the
signature is shared with the other `_fetch_*` helpers, and the write path still
uses it (`store.write_records(...)` on success).

Docstring paragraph, **after**:

```
    Middle element is the SIZE IN BYTES of the log fetched THIS invocation,
    not the body — a caller must never be handed a ~1.5 MB payload it does not
    need (a live probe measured one log at 1,497,943 bytes). It is None on
    every path that did not fetch, INCLUDING a successful dedup skip: sizing an
    already-captured log would mean gunzipping it off disk for a number nobody
    uses, and the compressed on-disk size is a different quantity that must not
    travel through the same field. The orchestrator counts dedup skips
    separately.
```
