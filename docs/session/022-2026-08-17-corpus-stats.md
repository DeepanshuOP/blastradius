## 3. Implementation Details

`analysis/corpus_stats.py` was created with:
1. **Read-Only SQLite Access & Lock Safety:**
   Connects to `file:data/state/cursor.db?mode=ro` with `timeout=5.0`. Catches `sqlite3.OperationalError` gracefully and marks output as stale with a warning rather than crashing.
2. **Unified Single-Pass Filesystem Scan:**
   Walks `data/raw/` in a single traversal, accumulating apparent bytes (`st_size`), on-disk block allocation (`st_blocks * 512`), file count, directory count, and discovering `runs.jsonl.gz` and `jobs.jsonl.gz` paths.
3. **Deduplicated Entity Extraction:**
   Parses `runs.jsonl.gz` and `jobs.jsonl.gz` into memory sets to deduplicate workflow runs and individual jobs by `id`.
4. **Frame Alignment & Mismatch Accounting:**
   Joins active repository directories (`<owner>__<repo>` and `<owner>/<repo>`) against `data/frame/frame_v1.csv` to stratify by language and verify 0 join mismatches.
5. **Phase 0 Exit Criteria Audit:**
   Evaluates all 5 criteria from ROADMAP §8.6. Inspects `/proc` safely to determine uninterrupted daemon uptime. Formats unmeasured operational criteria (4 and 5) as `NOT MEASURABLE FROM DATA` with unsoftened `NOT MET` status.
6. **Log Isolation Guard (Predicted Failure 3):**
   Omits dynamic `pytest` invocation within the table script to strictly preserve request log isolation (`logs/requests.jsonl`) per ROADMAP §8.2 and §34.1 Rule 6, providing direct manual verification commands (`make test`).
