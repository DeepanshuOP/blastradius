## 3. Step 2: Implementation of `analysis/expiry_cliff.py`

Implemented `analysis/expiry_cliff.py` (280 lines) to deterministically:
1. Snapshot all `runs.jsonl.gz` paths.
2. Parse each run object, deduplicating by `id`.
3. Compute age in days as `(now_utc - run_started_at)`.
4. Calculate age distribution metrics for all runs and failed runs.
5. Compute the recoverable window breakdown for failed runs.
6. Generate a top-10 priority work list of repositories with failed runs in the 60–90d band.
7. Generate a 32-repository comprehensive breakdown table.
8. Output the markdown report to `paper/generated/expiry_cliff.md` and print to stdout.
