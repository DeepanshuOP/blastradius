# Final Submission Gate

## Gate A — Scientific Integrity

- [ ] Every important claim has evidence or an appropriate citation.
- [ ] No invented result, dataset, baseline, metric, or implementation detail.
- [ ] No unsupported SOTA/best/first/novel claim.
- [ ] Scope of conclusions matches the evaluated setting.
- [ ] Limitations are stated honestly.

## Gate B — Human Authorship / Originality

- [ ] The author has personally reviewed the final wording.
- [ ] No source paper has been used as a prose template.
- [ ] No copied sentence or distinctive source phrasing remains.
- [ ] Literature is used for evidence and positioning, not copied language.
- [ ] No attempt has been made to manipulate AI-detection or plagiarism systems.

## Gate C — Reproducibility

- [ ] Dataset/split and preprocessing are stated.
- [ ] Key implementation details are stated.
- [ ] Evaluation metrics are defined.
- [ ] Baseline protocol is clear enough to interpret the comparison.
- [ ] Important figures/tables can be traced back to project artifacts.

## Gate D — Conference Format

- [ ] Correct conference class/template is used.
- [ ] Page limit is respected.
- [ ] Title/abstract rules are respected.
- [ ] Author and affiliation information is correct.
- [ ] Figures/tables/captions follow the template.
- [ ] Acronyms, units, equations, citations, and references are consistent.
- [ ] All template placeholder/guidance text is removed.

## Gate E — Reader Clarity

- [ ] One message per paragraph.
- [ ] First sentence of each paragraph makes its purpose clear where practical.
- [ ] Terminology is stable.
- [ ] Transitions explain cause, contrast, consequence, refinement, or example.
- [ ] The story can be summarized in a few sentences without losing the main contribution.

## Release Rule

Do not call the manuscript submission-ready if any hard scientific-integrity or template-compliance gate is unresolved.
