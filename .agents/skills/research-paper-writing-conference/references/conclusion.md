# Conclusion Writing Guide

## Structure

1. Restate the solved problem and core idea.
2. Summarize the strongest evidence.
3. State the practical or scientific takeaway.
4. State an honest limitation.
5. Give a concrete next direction when appropriate.

## Limitation Guidance

Prefer limitations tied to the evaluated task, setting, data regime, assumptions, or deployment scope.

Do not hide a serious technical weakness behind vague language. If a technical defect affects the conclusions, it belongs in the paper's limitations and discussion.

## Final Check

The Conclusion should not introduce a new claim that was not established earlier in the paper.
