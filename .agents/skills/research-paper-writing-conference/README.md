# Research Paper Writing — Conference / Human-Authored Skill

A small adaptation of the public `Master-cai/Research-Paper-Writing-Skills` workflow, itself curated from Prof. Peng Sida's open research-writing notes.

This package keeps the original story-first, section-by-section, reverse-outlining, claim-evidence, and adversarial-review approach, and adds:

- human-authored submission mode;
- originality/plagiarism safeguards;
- project evidence/provenance checks;
- IEEE conference-template checks;
- a final submission gate.

## Antigravity installation

For workspace scope, place the folder here:

`.agents/skills/research-paper-writing-conference/`

For global Antigravity/IDE installs, current Google guidance documents:

`~/.gemini/config/skills/`

Place the entire skill folder inside that directory.

The folder must contain `SKILL.md` at its root.

## Typical use

Open the paper/project workspace and ask the agent to use `research-paper-writing-conference` for the specific paper task. The skill is designed to load only the relevant reference files as needed.

## Important

This skill does not guarantee that external plagiarism or AI-detection systems will classify a manuscript in any particular way. Its goal is to keep the research author-driven, evidence-grounded, original in wording, and faithful to the supplied sources and experiments.
